# P2P Beacon - Обновление Архитектуры UI & UX (v2)

Этот документ заменяет предыдущие концепты. Вся визуальная разработка должна строго следовать этим новым правилам брендинга и логики. Приложение использует Tailwind CSS v4 и Mapbox GL. Все финансовые метрики строго в USD.

## 1. Брендинг и Цвета (Неоновый стиль флага РФ)

Главный визуальный стиль — **"Маяк" (The Beacon)**: сигнал во тьме. Мы используем мощный контраст Неонового Белого, Неонового Синего и Неонового Красного (цвета флага РФ), наложенные на глубокую темную тему.

### Базовые индикаторы на карте (Impact Map):

- **Зона бедствия (Crisis):** Неоновый красный (Активный сбор) - `#FF0000` / `bg-red-600` с сильным свечением. (Уже работает в `aid-points` как `status: 'red'`).
- **Зона закрыта (Resolved):** Неоновый зеленый - `#10B981` / `bg-emerald-600` (Уже работает как `status: 'green'`).



### Эстетика платформы ("Свет маяка"):

Все счетчики и элементы интерфейса поверх карты должны быть в **неоновом стиле RU**, выделяясь на темном фоне `#0f172a`).

- **Основной Неоновый Белый (Счетчики/Главный текст):** Интенсивный неоновый белый.
- **Вторичный Неоновый Синий (Прогресс-бары/Акценты):** Глубокий, электрический синий цвет.
- **Третичный Неоновый Красный (Кнопки действий):** Используется для привлечения максимального внимания к кнопкам доната.



### Дизайн компонентов ("Кристальная" кнопка)

Все главные кнопки должны быть в стиле **"Кристалл" (Crystal)**.

- **Стиль:** Глассморфизм (полупрозрачное стекло с размытием фона `backdrop-blur-md`).
- **Правило:** Прозрачная основа, тонкая граница и сильное внутреннее и внешнее неоновое свечение.



## 2. Новая механика: Краудфандинг через свайпы (TikTok style)

Карта служит для глобального обзора. Лента свайпов открывается только для зарегистрированных пользователей и служит для точечного финансирования.

### Фаза 1: Регистрация (Mail API)

- Доступ к профилям и ленте закрыт до регистрации.
- Регистрация происходит через подтверждение по Email (Mail API).



### Фаза 2: Лента профилей (UX в стиле TikTok)

- **Паттерн:** Вертикальная лента свайпов (с фокусом на мобильные устройства) с полноэкранными видео/фото.
- **Логика свайпов:**
  - **Свайп вправо:** Добавить проект в "Избранное" / Подумать.
  - **Свайп влево:** Пропустить (убирает проект из текущей выдачи).
  - **Двойной тап/Клик:** Прямой донат P2P (Вызывает кристальную кнопку "ПОМОЧЬ $1").
- **Карточка проекта:** Каждый сбор занимает весь экран. Должны быть видны:
  - Фоновое медиа.
  - Прогресс в USD (строго отформатированный).
  - Кристальная кнопка доната.
  - Индикатор P2P прозрачности.
